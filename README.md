# LabGram 🧪

شبكة اجتماعية عربية لأخصائيي المختبرات والمهنيين الصحيين — صفحة واحدة (HTML/JS) تعمل على GitHub Pages مع Supabase.

## المزايا
- تسجيل حساب / دخول / استعادة كلمة المرور (Supabase Auth)
- منشورات نصية وصور (رفع وضغط تلقائي للصور) مع أقسام: الأنسجة، الخلايا، الأحياء الدقيقة، الدم، الكيمياء، الجودة…
- إعجاب (ومنه النقر المزدوج على الصورة)، تعليقات، مشاركة رابط المنشور
- متابعة الزملاء + صفحة "أتابعهم" + اقتراحات للمتابعة
- ملف شخصي بصورة وخلفية ملوّنة قابلة للاختيار، وشبكة منشورات
- تنبيهات تلقائية (إعجاب، تعليق، متابعة)
- بحث عن الزملاء ومعرض لأحدث الصور
- صلاحية المالك (owner): شارة ✓ وحذف أي منشور أو تعليق
- وضع ليلي ونهاري، تصميم زجاجي بخلفية متحركة، متجاوب مع الجوال

## التشغيل
1. في Supabase: **SQL Editor → New query** والصق محتوى `schema.sql` ثم **Run** (مرة واحدة، وآمن لإعادة التشغيل).
2. في **Authentication → URL Configuration** أضف رابط موقعك (GitHub Pages) إلى *Site URL* و *Redirect URLs*.
3. افتح الموقع وسجّل حسابك.
4. لتصبح مالكاً، شغّل في SQL Editor:
   ```sql
   update public.lg_profiles set role = 'owner' where username = 'اسم_المستخدم';
   ```

> الجداول كلها تبدأ بـ `lg_` والصور في bucket باسم `lg-media`.
